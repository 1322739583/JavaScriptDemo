语句和表达式我们平时用着都没什么感知，不会停下来说，这是语句，这是表达式。
但是涉及到一些具体概念的时候，我们就有必要分清这两者了。

在es5时代，有下面这段经典的IIFE立即执行函数表达式，用法就非常的古怪，非常的难以理解。你还要结合历史背景才能明白这个表达式的含义。具体见立即执行表达式目录。

而写这篇文章的原因，实际上是源于下面这套面试题：
这个题目非常的刁钻，你不明白概念根本搞不清楚。

```js
// IIFE（立即执行函数表达式)
(function () {
  "use strict"; //严格模式不会穿透和传递，设计的时候就是为了防止老代码崩溃
  foo(); //这是裸调用，和在外面直接调用没有区别，this是没有作用域的概念的，只有变量才有作用域概念
})();

function foo() {
  // "use strict";
  console.log("this is foo: ", this); //因为这个函数没有开启严格模式所以指向window/global
}
```
