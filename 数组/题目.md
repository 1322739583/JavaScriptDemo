# JavaScript 数组练习题

1. 请指出以下代码中各数组方法调用后，哪些会直接修改原数组？哪些不会？
   - `push()`、`pop()`、`shift()`、`unshift()`
   - `slice()`、`splice()`、`concat()`
   - `sort()`、`reverse()`
   - `map()`、`filter()`、`reduce()`

2. 在 React 或 Vue 等框架的状态管理中，为什么不能直接执行 `list.push(newItem)` 或 `list.reverse()` 然后更新状态？应该如何写？

3. ES2023 引入了哪几个不改变原数组的对应新方法？它们分别对应哪些传统方法？

4. 简述 `push()`、`pop()`、`shift()`、`unshift()` 这四个方法的返回值分别是什么？为什么有的返回长度，有的返回被操作的元素？

5. 简述 `splice()` 和 `slice()` 的参数含义、返回值以及对原数组的影响。

6. 什么是类数组（Array-like）？如何将 `arguments` 或 DOM `NodeList` 转为真实数组？`Array.from()` 和 `[...items]` 在什么情况下会有不同的表现？

7. 请按演进顺序列举 JavaScript 中遍历数组的常见方式。为什么在数组上极不推荐使用 `for...in`？

8. `forEach` 回调函数中能否使用 `break` 提前终止？如果在 `forEach` 中执行 `await` 会出现什么现象？

9. `for...of` 如何同时获取数组的索引与元素？为什么解构时是 `[index, item]`？`arr.entries()` 返回的具体是什么？

10. 请写出以下代码的控制台输出结果：

    ```

11. 请写出以下代码的控制台输出结果：

    ];
    ```
    为什么直接使用 `new Set(cart)` 无法去重？请编写一个时间复杂度为 $O(N)$ 的去重函数 `uniqueById(cart)`，只保留首次出现的商品。
