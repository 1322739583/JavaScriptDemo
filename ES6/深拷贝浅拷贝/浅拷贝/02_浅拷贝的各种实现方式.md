# 浅拷贝的各种实现方式大全

在 JavaScript 中，除了最常用的 `...` 和 `Object.assign`，其实还有很多方法能实现浅拷贝，特别是针对**数组**。

## 1. 对象的浅拷贝方式
* **扩展运算符 (Spread Operator)**：`const copy = { ...obj };` （最常用、最推荐）
* **Object.assign()**：`const copy = Object.assign({}, obj);`
* **手写循环**：通过 `for...in` 循环拷贝第一层属性。

## 2. 数组的专属浅拷贝阵营
因为数组也是对象，所以它完全适用扩展运算符，此外还有它专属的原型方法：
* **`[...arr]`**：扩展运算符（ES6 引入）。
* **`arr.slice()`**：原本用于截取数组，不传参时默认截取全部，从而实现浅拷贝。
* **`[].concat(arr)`**：原本用于合并数组，与空数组合并也能实现浅拷贝。
* **`Array.from(arr)`**：将类数组或可迭代对象转为真正的数组，顺带实现浅拷贝。
