# 赋值与浅拷贝的核心区别

很多人容易把“直接赋值”和“浅拷贝”搞混。它们的区别在于**是否在堆内存中创建了新的对象外壳**。

## 1. 赋值 (Assignment)
例如：`const obj1 = obj;`

* **本质**：复制了对象在内存中的**地址指针**。
* **结果**：`obj1` 和 `obj` 指向同一个对象。
* **修改影响**：无论是修改第一层（`obj1.name`）还是第二层（`obj1.info.age`），原对象 `obj` 都会跟着同步变化。它们是彻头彻尾的同一个东西。

## 2. 浅拷贝 (Shallow Copy)
例如：`const copy = { ...obj };`

* **本质**：在堆内存中**新建了一个对象外壳**，然后把原对象第一层的所有键值对搬进去。如果是引用类型的值，搬运的是内存地址。
* **修改影响**：
  * 修改第一层的基本类型数据，**互不影响**。
  * 修改第二层及以下的嵌套对象，**会互相影响**（因为子对象仍然共享着同样的内存地址）。
