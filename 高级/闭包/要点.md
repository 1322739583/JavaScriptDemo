闭包单独使用平平无奇，和函数嵌套 / 高阶函数一起使用的时候才会体现出它的价值。
闭包的形成主要依赖“函数嵌套”，而“高阶函数”是让闭包发挥威力最常见的手段。“高阶函数”不一定有闭包。
闭包还涉及到强引用的概念，因为闭包的作用就是在嵌套函数里面把本来应该被销毁的变量“拽住”，实际上，起到拽住作用的是“强引用”。

闭包这个词本身也非常有意思。Closure是动词close的名词化。

提出者：1964 年由著名计算机科学家 Peter Landin 在研究表达式时首次提出，后来在 1975 年被 Scheme 语言正式发扬光大，最终被所有现代语言（JavaScript、Python、Swift 等）继承。

下面这个函数里面使用到了message变量，这个变量不是函数内部的，这个函数就像漏了一个洞，是不完整的。

```js
function inner() {
  console.log(message);
}
```

为了把这个函数完整的包（close）起来，就有了闭包的概念，闭包这个词其实翻译的非常好的。
“The function closes over its environment.”（函数闭合了它所依赖的外部环境）

原始的概念实际上是比较容易理解的，嵌套函数实际上是深了一层。这个例子的核心在于inner()函数和count变量符合闭包概念。
因为嵌套让人感觉很复杂，实际上这里的重点是inner而不是outer。count变量对于inner来说是他的闭包资源，对于outer来说，他只是一个局部变量。

```js
function outer() {
  let count = 0; // 👈 到底算内部还是外部？！

  return function inner() {
    count++;
  };
}
```
