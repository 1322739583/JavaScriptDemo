# 网络通信与跨域（HTTP & CORS）模块说明

本目录系统梳理了前端开发中关于**浏览器同源策略**、**跨域拦截机制**以及**企业级解决方案**的核心知识。

---

## 知识脉络与学习顺序

1. **[01_什么是同源与跨域.html](./01_什么是同源与跨域.html)**
   - 彻底搞懂“同源”的三要素：**协议、域名、端口**必须完全一致；
   - 对比常见的各种场景（子域名、端口不同、http与https不同）；
   - 认识控制台著名的 CORS 报错长什么样。

2. **[02_跨域的底层运行机制剖析.html](./02_跨域的底层运行机制剖析.html)**
   - 揭秘核心冷知识：跨域时请求**其实已经发到后端并执行完毕了**，是数据返回浏览器时被拦截；
   - 搞懂为什么 `<img>`、`<script>` 不跨域，而 `fetch`、`XMLHttpRequest` 会被拦截。

3. **[03_简单请求与OPTIONS预检请求.html](./03_简单请求与OPTIONS预检请求.html)**
   - 剖析什么是“简单请求”，什么是“非简单请求”；
   - 搞清楚为什么携带 `Authorization` 头或 `application/json` 会凭空多出一次 `OPTIONS` 请求；
   - 了解预检请求的协商机制。

4. **[04_解决跨域的三大主流方案.md](./04_解决跨域的三大主流方案.md)**
   - **开发环境**：Vite / Vue CLI 本地开发服务器代理原理与配置；
   - **生产环境（最主流）**：Nginx 反向代理配置与原理；
   - **服务端支持**：CORS 响应头配置；
   - **历史技术**：JSONP 的原理与淘汰原因。
