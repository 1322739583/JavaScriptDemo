# 高阶函数（Higher-Order Function）核心要点

## 一、定义与判断标准
满足以下**任意一个条件**的函数，就是高阶函数：
1. **接收一个或多个函数作为参数**（函数作为参数）
2. **返回一个函数**（函数作为返回值）

> 💡 **为什么叫“高阶”？**
> * 普通（一阶）函数处理的是**基础数据**（数字、字符串、对象）。
> * 高阶函数处理的是**“函数本身”**，它站在更高的抽象维度上操作程序逻辑。

---

## 二、三大应用流派

| 流派 | 核心思想 | 现实比喻 | 典型代表 |
| :--- | :--- | :--- | :--- |
| **1. 函数作为参数** | **行为代工 / 逻辑注入**：外层只管模板流程（如遍历、异步等待），把核心判断/处理逻辑委托给传进来的函数。 | 快递代收点（外层管运输，具体的收件人核验规则由你传给他的委托书决定） | `Array.prototype.map`<br>`filter`<br>`sort` |
| **2. 函数作为返回值** | **函数工厂 / 参数预设**：利用闭包预先锁住通用参数，批量生产专用小工具。 | 模具冲压机（先装上模具，源源不断压出同类规格的零件） | `createGreeter("Hello")`<br>柯里化函数 |
| **3. 既收函数，又返回函数** | **函数增强器 / 装饰器**：不碰原函数内部代码的前提下，在运行前后加特效（面向切面编程 AOP）。 | 给素颜车加装防滚架、氮气加速 | **防抖（debounce）**<br>**节流（throttle）**<br>执行耗时统计（withTimer） |

---

## 三、闭包与高阶函数的“终极合体”

回到最初的问题：为什么学防抖节流时容易晕？
因为防抖节流是**高阶函数第 3 流派**与**闭包强引用**的合体产物：

```javascript
function debounce(fn, delay) {
  let timer = null; // 🔒 闭包：为新函数配备私有长期状态背包

  // 🚀 高阶函数：接收 fn，返回加工增强后的新函数
  return function(...args) {
    if (timer) clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
      timer = null;
    }, delay);
  };
}
```

* **高阶函数负责“皮囊”**：把普通的 `fn` 包装成带有倒计时机制的新函数。
* **闭包负责“灵魂”**：让多次触发的新函数能够持续读写同一个 `timer`。
