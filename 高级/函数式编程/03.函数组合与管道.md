# 03. 函数组合与管道（Compose & Pipe）

> 函数组合是函数式编程中**组织复杂业务逻辑、替代“洋葱嵌套地狱”的核心手段**。Redux 的 `applyMiddleware` 底层原理正是 `compose`。

---

## 一、 为什么需要函数组合？（告别洋葱嵌套）

假设我们需要对一个数字做三步加工：
1. 先加 10（`add10`）
2. 再乘 2（`multiply2`）
3. 最后减 5（`minus5`）

在传统命令式代码中，如果不用中间变量，嵌套调用会写成极难阅读的**洋葱式倒叙嵌套**：
```javascript
const result = minus5(multiply2(add10(5))); // 5 + 10 = 15 ➔ 15 * 2 = 30 ➔ 30 - 5 = 25
```
嵌套越深，代码越反人类，阅读时必须从最内层一层一层往外倒着看。

---

## 二、 Compose 与 Pipe 的区别

* **`compose`（从右向左执行）**：符合数学上的复合函数定义 $f(g(x))$，先执行后面的，再执行前面的；
* **`pipe`（从左向右执行，管道）**：符合人类从左往右的自然阅读习惯，像流水线一样把数据向前推送。

```javascript
// 使用 compose：
const pipeline = compose(minus5, multiply2, add10);
pipeline(5); // 25

// 使用 pipe：
const pipeline2 = pipe(add10, multiply2, minus5);
pipeline2(5); // 25
```

## 三、 大厂高频手写题：手写 `compose` 与 `pipe`

### 1. 手写 `compose`（基于 `reduceRight` 实现）
```javascript
function compose(...funcs) {
  if (funcs.length === 0) return arg => arg;
  if (funcs.length === 1) return funcs[0];

  return function(initialValue) {
    // 从右往左执行：reduceRight
    return funcs.reduceRight((acc, fn) => fn(acc), initialValue);
  };
}
```

### 2. 手写 `pipe`（基于 `reduce` 实现）
```javascript
function pipe(...funcs) {
  if (funcs.length === 0) return arg => arg;
  if (funcs.length === 1) return funcs[0];

  return function(initialValue) {
    // 从左往右执行：reduce
    return funcs.reduce((acc, fn) => fn(acc), initialValue);
  };
}
```

## 四、 行业经典案例：Redux 源码中的 `compose`

在著名的前端状态管理库 **Redux** 源码中，它的 `compose` 函数写得极具艺术感（纯 ES6 箭头函数单行实现）：

```javascript
// Redux 官方源码：
export default function compose(...funcs) {
  if (funcs.length === 0) return arg => arg;
  if (funcs.length === 1) return funcs[0];

  return funcs.reduce((a, b) => (...args) => a(b(...args)));
}
```
Redux 就是利用这个函数，把所有中间件（Logger、Thunk、Saga）像洋葱皮一样无缝包裹在 `dispatch` 外面！
