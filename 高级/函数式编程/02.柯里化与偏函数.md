# 02. 柯里化与偏函数（Currying & Partial Application）

> 柯里化（Currying）是各大厂技术面试中**高频必考的手写题与核心理论题**。以逻辑学家 Haskell Curry 的名字命名。

---

## 一、 什么是柯里化？

**一句话定义**：  
将一个**接收多个参数的函数**，转换成**一系列“每次只接收单一参数（或部分参数），并返回接收剩余参数的新函数”**的技术。

```javascript
// 普通函数（一次性接收所有参数）：
function add(a, b, c) {
  return a + b + c;
}
add(1, 2, 3); // 6

// 柯里化后的函数（分步接收参数）：
function curriedAdd(a) {
  return function(b) {
    return function(c) {
      return a + b + c;
    };
  };
}
curriedAdd(1)(2)(3); // 6
```

---

## 二、 柯里化在工程中有何实际价值？

很多同学觉得 `f(1)(2)(3)` 写法花里胡哨，在现实中它有两个极具价值的应用：

### 1. 参数复用（固定常用上下文）
假设我们要做日志打印或正则校验：
```javascript
// 普通函数：每次都要重复传类型
function log(date, type, message) {
  console.log(`[${date}] [${type}] ${message}`);
}
log("2026-10-26", "ERROR", "网络崩溃");
log("2026-10-26", "ERROR", "用户未授权");

// 柯里化后：
const curriedLog = curry(log);
const logTodayError = curriedLog("2026-10-26")("ERROR"); // 提前固定前两个参数！

// 后续使用极其爽快：
logTodayError("网络崩溃");
logTodayError("用户未授权");
```

### 2. 延迟执行与管道适配
参数可以分批次传入，只有当所有需要的参数全部凑齐时，才真正触发核心计算。

---

## 三、 大厂高频手写题：通用柯里化函数 `curry()`

面试官通常要求：**“请手写一个通用的 `curry(fn)` 函数，使其支持 `curried(1)(2)(3)` 和 `curried(1, 2)(3)` 等任意分步传参形式。”**

### 标准实现源码：
```javascript
function curry(fn) {
  return function curried(...args) {
    // 关键判断：如果当前收集到的参数数量，已经达到了原函数的形参个数 (fn.length)
    if (args.length >= fn.length) {
      // 凑齐了，直接执行原函数并返回结果
      return fn.apply(this, args);
    } else {
      // 参数还没凑齐，返回一个新函数，继续递归收集后续传入的参数
      return function(...nextArgs) {
        return curried.apply(this, args.concat(nextArgs));
      };
    }
  };
}

// ---------------- 测试验证 ----------------
function sum(a, b, c) {
  return a + b + c;
}

const curriedSum = curry(sum);

console.log(curriedSum(1, 2, 3)); // 6 (支持一次性全传)
console.log(curriedSum(1)(2, 3)); // 6 (分两次传)
console.log(curriedSum(1)(2)(3)); // 6 (分三次单参传)
```
