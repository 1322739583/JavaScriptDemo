# 函数式编程（Functional Programming, FP）体系总览

> 函数式编程与面向对象编程（OOP）并列为现代软件工程的两大顶级编程范式。在现代前端生态（React Hooks、Redux、Lodash/Ramda）中，函数式编程占据了核心基石地位。

## 四大核心支柱速览

| 模块 | 核心概念 | 经典应用场景 |
| :--- | :--- | :--- |
| **01. 纯函数（Pure Function）** | 相同输入必有相同输出，绝不产生外部副作用 | React 组件渲染、Redux Reducer、前端单测 |
| **02. 柯里化（Currying）** | 将接收多个参数的函数，转化为分步接收单个参数的函数链 | 参数复用、延迟计算、通用事件处理中间件 |
| **03. 函数组合（Compose / Pipe）** | 将多个小函数串联成一条流水线，后一个接收前一个的输出 | 中间件架构（Redux 中间件、Koa 洋葱模型）、复杂数据清洗 |
| **04. Point-Free 风格** | 不提具体参数名，直接连接函数实体（方法引用） | `arr.map(Number)`、`arr.filter(Boolean)` 等优雅函数式管道 |

## 为什么现代前端必须掌握函数式编程？

1. **不可变数据流（Immutability）**：避免对象在内存中被暗中篡改，大幅降低多模块协作中的隐蔽 Bug；
2. **极佳的可测试性（Testability）**：纯函数无需 Mock 复杂的外部上下文，随时随地跑单测；
3. **高并发与现代框架契合度**：React 从 Class 组件全面转向 Function 组件与 Hooks，本质上就是向函数式编程的全面拥抱。
