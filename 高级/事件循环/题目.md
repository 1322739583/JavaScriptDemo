# 第一部分：核心概念与原理问答（口试高频）

### 概念题 1：什么是事件循环（Event Loop）？为什么单线程的 JavaScript 需要它？
* **考察意图**：考察是否理解单线程与异步非阻塞的矛盾，以及 GUI 架构的事件循环哲学。
* **思考要点**：
  * JavaScript 为什么必须是单线程（多线程操作 DOM 会带来什么灾难）？
  * 单线程自己怎么解决等待耗时任务的问题？
  * 宿主环境多线程（Web APIs）与调用栈、任务队列是如何协作的？

---

### 概念题 2：前端中常见的宏任务（Macrotask）与微任务（Microtask）分别有哪些？
* **考察意图**：考察知识面的完整度与对 API 归属的精准辨识度（最基础的必考清单）。
* **思考要点**：
  * 浏览器环境中有哪些宏任务？（至少说出 4 种）
  * 浏览器环境中有哪些微任务？（至少说出 3 种）
  * Node.js 环境中特有的宏任务与微任务分别是什么？
  * 【易混淆辨析】：`requestAnimationFrame`（rAF）算宏还是微？`new Promise(executor)` 算宏还是微？

---

### 概念题 3：宏任务（Macrotask）与微任务（Microtask）是如何区分的？凭什么他是宏任务，他是微任务？
* **考察意图**：考察是否只死记名字，还是理解规范与宿主底层的权责边界。
* **思考要点**：
  * 从“管辖权与出生地”（宿主 W3C 规范 vs JS 引擎 ECMA-262 规范）角度解释。
  * 从“业务紧迫性”（等得起 vs 绝对等不起、状态一致性）角度解释。

---

### 概念题 4：请简述单轮事件循环的完整执行时序。
* **考察意图**：考察是否掌握事件循环的运转核心法则与渲染时机。
* **思考要点**：
  * 初始执行从哪里开始？
  * 什么时候清空微任务队列？
  * UI 渲染发生在什么节点？
  * 下一个宏任务什么时候被取出？

---

### 概念题 5：`async / await` 是宏任务还是微任务？为什么它“等不起”？
* **考察意图**：考察对语法糖底层转换及协程/状态竞争的理解。
* **思考要点**：
  * `async/await` 的底层本质是什么？
  * 如果 `await` 后面的代码被设计成宏任务，会引发什么逻辑和视觉灾难？

---

### 概念题 6：事件循环与浏览器 UI 渲染（Render）的时机是什么关系？
* **考察意图**：考察对 60FPS 帧率、页面卡顿与微任务死锁的底层认知。
* **思考要点**：
  * 微任务清空后，浏览器一定会马上渲染吗？为什么？
  * `requestAnimationFrame`（rAF）处于事件循环的哪个具体阶段？
  * 宏任务无限递归 vs 微任务无限递归，哪一个会导致页面卡死？为什么？

---

### 概念题 7：Node.js 的事件循环与浏览器的事件循环有什么区别？
* **考察意图**：考察全栈与跨运行时架构视野。
* **思考要点**：
  * 浏览器的实现依据与 Node.js 底层 `libuv` 的区别。
  * Node.js 常见的核心阶段（Timers、Poll、Check）。
  * Node.js 专属的 `process.nextTick` 与 `setImmediate` 的特点与优先级。

# 第二部分：代码输出顺序推演（笔试必考）

## 题目一：辨别 Promise 的同步执行与微任务（基础必考）

请写出以下代码的控制台输出顺序：

```javascript
console.log('1');

setTimeout(() => {
  console.log('2');
}, 0);

new Promise((resolve) => {
  console.log('3');
  resolve();
  console.log('4');
}).then(() => {
  console.log('5');
});

console.log('6');
```

## 题目二：`async / await` 与 `Promise` 的交织（进阶高频）

请写出以下代码的控制台输出顺序：

```javascript
async function async1() {
  console.log('1');
  await async2();
  console.log('2');
}

async function async2() {
  console.log('3');
}

console.log('4');

setTimeout(() => {
  console.log('5');
}, 0);

async1();

  console.log('6');
  resolve();
}).then(() => {
  console.log('7');
});

console.log('8');
```

## 题目三：宏任务与微任务的嵌套循环（大厂真题）

请写出以下代码的控制台输出顺序：

```javascript
console.log('1');

setTimeout(() => {
  console.log('2');
  Promise.resolve().then(() => {
    console.log('3');
  });
}, 0);

new Promise((resolve) => {
  console.log('4');
  resolve();
}).then(() => {
  console.log('5');
  setTimeout(() => {
    console.log('6');
  }, 0);
});

console.log('7');
```
