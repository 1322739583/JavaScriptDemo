# JavaScript this 指向核心秘籍

要想掌握 this 指向问题，牢记四个法则，能解决 90% 的问题。
但面对环境（Node/浏览器）与模式（严格/非严格）的多层叠加，死记硬背排列组合极易混淆。

最实战、最清晰的心法是：**像流水线安检一样，按顺序走过这“三道门”**。

---

## 🚀 “三道门”秒判心法

```text
【第 1 道门：看基因】
它是箭头函数 () => {} 吗？
  ├── 是 ──> 立即通关！直接找它定义时的外层词法作用域是谁，跟谁调用、怎么调用、严格与否毫无关系。
  └── 否 ──> 进入第 2 道门。

【第 2 道门：看手势】
它怎么被调用的？（看调用姿态的优先级）
  ├── 1. 带着 new (new Foo()) ──> 指向新创建的实例对象。
  ├── 2. 带着 call / apply / bind ──> 指向指定的那个目标对象。
  ├── 3. 带着点号 (obj.foo()) ──> 隐式绑定，指向紧邻点号左侧的 obj。
  └── 4. 啥都没带，独立裸调用 (foo()) ──> 进入第 3 道门。

【第 3 道门：仅裸调用时问一句】
当前是严格模式吗？
  ├── 是 ('use strict' / ES Module / Class 体内) ──> undefined
  └── 否 (普通非严格脚本) ──> 全局对象 (浏览器为 window，Node.js 为 global)
```
