01_XSS 跨站脚本攻击（Cross-Site Scripting）

一、什么是 XSS？

本质：黑客把恶意 JavaScript 脚本代码注入到你的网页中，浏览器以为是正常的网页代码并执行了它！

危害：盗取用户 Cookie、窃取密码、假冒用户发帖、挂马挖矿。

二、XSS 的三种主要类型：

  1. 存储型 XSS（最危险）：黑客在论坛发帖或评论区留言，内容包含 <script>steal(document.cookie)</script>。这串代码被保存进了后端数据库！每当其他用户打开这个帖子时，恶意代码从数据库拉出并在所有人的浏览器里执行！
  2. 反射型 XSS：恶意代码藏在 URL 参数里（如 http://site.com/search?q=<script>...</script>），诱骗受害者点击链接，服务器把参数未经转义直接拼进 HTML 返回执行。
  3. DOM 型 XSS：纯前端代码漏洞（比如使用了 innerHTML 或 document.write 直接插入未经过滤的用户输入）。

三、Vue/前端中如何防御 XSS？

  • 1. Vue 的天然护甲：Vue 默认的插值语法 {{ text }} 会自动将 <、> 转义为 HTML 实体编码（&lt;、&gt;），脚本无法执行！
  • 2. 慎用 v-html（高危入口）：必须渲染富文本时，强制使用三方库 DOMPurify 进行消毒清洗：
    const cleanHtml = DOMPurify.sanitize(dirtyHtml);
  • 3. 终极防御：Cookie 开启 HttpOnly：
    后端设置 Cookie 时带上 HttpOnly 标志。即使黑客成功注入了 JS 代码，通过 document.cookie 也绝对读不到该 Cookie！
