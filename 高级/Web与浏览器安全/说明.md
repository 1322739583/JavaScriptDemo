# Web 与浏览器安全模块说明

前端面试与真实项目中，**Web 安全（XSS、CSRF、点击劫持）** 是与性能优化、跨域通信并列的三大核心通识之一。

---

## 知识脉络与学习顺序

1. **[01_XSS跨站脚本攻击与防御.html](./01_XSS跨站脚本攻击与防御.html)**
   - 什么是 XSS？本质是**把恶意 JS 脚本注入网页并在受害者浏览器里执行**；
   - 存储型、反射型、DOM 型的区别；
   - Vue 中的防御机制（插值转义、`v-html` 的风险与 DOMPurify 净化）；
   - 核心防御底牌：Cookie 开启 `HttpOnly`。

2. **[02_CSRF跨站请求伪造与防御.html](./02_CSRF跨站请求伪造与防御.html)**
   - 什么是 CSRF？本质是**借刀杀人**（利用已有的 Cookie 身份凭证，冒充用户发起破坏操作）；
   - 四大防御策略：`SameSite` Cookie（Lax/Strict）、CSRF Token 校验、`Referer/Origin` 校验、关键操作短信验证码。

3. **[03_CSP与点击劫持防御.html](./03_CSP与点击劫持防御.html)**
   - 内容安全策略（CSP）：通过 HTTP 头限制只能向指定白名单发请求、加载脚本；
   - 点击劫持（透明 iframe 覆盖欺骗）与 `X-Frame-Options: SAMEORIGIN` 防御。
